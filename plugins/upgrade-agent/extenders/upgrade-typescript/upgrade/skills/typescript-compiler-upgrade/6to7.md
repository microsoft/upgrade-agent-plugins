# TypeScript 7.0 Migration (from 6.x)

**Package name changed**: `typescript` → `@typescript/native-preview`

`@typescript/native-preview` IS TypeScript 7 — the same compiler, rewritten as a native binary, using `tsgo` instead of `tsc` for compilation.

## Install

**npm:** `npm install -D @typescript/native-preview@latest`
**yarn:** `yarn add -D @typescript/native-preview@latest`
**pnpm:** `pnpm add -D @typescript/native-preview@latest`

## Upgrade Checklist

1. Install `@typescript/native-preview`
2. **Rename `tsc` → `tsgo` in `package.json` scripts** (only on the `@typescript/native-preview` hop; if the project is still on the `typescript` package, the build command stays `tsc`). Do this immediately after install and BEFORE `typescript_compile_package`. Edit each non-`node_modules` `package.json` by hand (or with an edit tool): replace script values where `tsc` is being invoked as the compiler — use the trailing-space guard (`"tsc "` → `"tsgo "`) so tool names like `tsc-alias` and `tscpaths` are untouched. The literal `"tsc"` with no arguments should be left alone unless you are certain it is only a compiler call; if unsure, ask the user. If the project keeps both packages installed (see Compatibility Note), some `tsc` invocations may intentionally target the classic compiler — review each rewritten line before committing.
3. Run `typescript_compile_package` to check for errors
4. Fix any deprecated feature errors — all TS6 deprecations are fully removed in TS7

## Forbidden Fixes — Do Not Suppress Errors

Do not paper over upgrade errors with suppression escape hatches. Specifically:

- **`ignoreDeprecations`** has no effect in TS7 — the deprecated options are fully removed. Never add it as a fix on this hop. Fix the underlying issue using the recipes in [5to6.md](./5to6.md).
- Do not add `// @ts-ignore`, `// @ts-expect-error`, or `// @ts-nocheck` to silence new errors.
- Do not cast to `any` (or widen types to `any`) just to make an error go away.
- Do not flip `tsconfig.json` strictness flags (`strict`, `noImplicitAny`, `strictNullChecks`, `skipLibCheck`, etc.) from their existing value to silence errors.

If an existing `ignoreDeprecations` entry is already in `tsconfig.json`, leave it as-is. If a real fix is genuinely out of scope, revert the upgrade for that package rather than committing a suppression.

## tsc → tsgo Replacements

| Before | After |
|--------|-------|
| `tsc` | `tsgo` |
| `tsc --noEmit` | `tsgo --noEmit` |
| `tsc --build` | `tsgo --build` |
| `tsc -b` | `tsgo -b` |
| `tsc -p tsconfig.json` | `tsgo -p tsconfig.json` |

Scripts that call bundlers (`tsup`, `vite`, `esbuild`, etc.) do not need changes.

## Compatibility Note

If tools require the TypeScript API (linters, formatters, bundlers generating `.d.ts` files), keep both packages installed:
```bash
npm install -D typescript @typescript/native-preview
```
